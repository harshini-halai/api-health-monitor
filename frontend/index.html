Frequently asked questions

What is website monitoring?

Automatically requesting your website at regular intervals and recording whether it responded, how fast, and with what status code.

How frequently are websites checked?

Every 5 minutes, and you can run a manual check at any time from the dashboard.

Can I monitor multiple websites?

Yes. Each account can monitor up to 25 websites.

Does monitoring work when my browser is closed?

Yes. Checks are run by the backend scheduler, not by your browser.

What does response time mean?

The time between sending the request and receiving the server's response headers, including any redirects, in milliseconds.

What do Operational, Degraded and Down mean?

Operational: a successful 2xx response that arrived quickly. Degraded: the server responded but something is off (a redirect that did not resolve, a 4xx response, or a very slow 2xx). Down: a 5xx error, or the site could not be reached (timeout, DNS or SSL failure).

How does the Chrome extension connect?

Open Chrome Extension in your dashboard and generate a one-time pairing code (valid for a few minutes). Paste it into the extension popup, or use 1-click connect. The extension then gets its own revocable token, and you can disconnect it from the dashboard at any time. For now it is installed manually (download the zip from the dashboard and load it in Chrome developer mode).

What happens when my website goes down?

The check is recorded as Down with the reason and the dashboard shows it immediately. If you have verified an alert email address, you get a Down email after the number of consecutive failed checks you set (1 to 5), and a Recovered email when the site is back. Incidents are listed under Alerts & Incidents. Push notifications are not available yet.
