# Website Health Monitor ? Chrome Extension (Manifest V3)

1. Open `chrome://extensions/` in Chrome and enable **Developer mode**.
2. Click **Load unpacked** and select this `extension/` folder.
3. Log into your dashboard (`http://127.0.0.1:8000/dashboard`), open **Chrome Extension**, and click **Connect Extension** to generate a single-use code (`XXXX-XXXX`).
4. Paste the code into the extension popup and click **Connect Extension**.
