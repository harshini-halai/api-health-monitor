# Website Health Monitor ? Chrome Extension (Manifest V3)

## Installation
1. Open `chrome://extensions/` in Chrome and enable **Developer mode**.
2. Click **Load unpacked** and select this `extension/` folder.

## Connecting & Monitoring
1. Open your Website Health Monitor dashboard and navigate to **Chrome Extension**.
2. Click **Connect Extension (1-Click)** ? the extension pairs automatically without manual code entry.
3. Visit any website in Chrome, open the extension popup, and click **+ Monitor** to register and check it immediately.
